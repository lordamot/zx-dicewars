# DiceWars ZX 8x8 font, hand-drawn as text bitmaps.
#
# Format: "char X" (X = the character, or a name: space, dice1..dice8),
# followed by exactly 8 rows of 8 columns, '#' = ink pixel, '.' = empty.
# tools/font_gen.py compiles this into build/font8.asm:
#   font8:    64 glyphs, ASCII 32..95 (missing chars are blank)
#   dicefont: 8 bold digits 1..8 used for dice counts on the map.
# Glyph style: 6 px wide (cols 0-5), 7 px tall (rows 0-6); col 6-7 and
# row 7 stay empty so text has natural spacing. Dice digits are bolder
# (2 px strokes) and may use the full 8x8 box.
